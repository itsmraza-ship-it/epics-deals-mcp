## About the plugin
The Epics Deals plugin provides free, read-only tools: LLC formation costs by
state, state comparisons, EIN timelines, IRS compliance deadlines, ITIN
guidance and tax filing estimates. It collects no personal data and requires
no account.

## Issues
If a tool returns an unexpected figure, email info@epicsdeals.com with the
question you asked and the answer you received. State fees change from time to
time; figures are verified against state schedules for AZ, CO, DE, MO, MT, NM
and WY and cross-checked for all other states.
